# Site de Inteligência Artificial - Jogo Interativo

Um site educativo e interativo sobre Inteligência Artificial com um jogo que permite aos usuários aprender arrastando palavras para completar frases.

## 📋 Características

- **Jogo Interativo de Arrastar**: Arraste palavras para completar frases sobre IA
- **5 Questões Educativas**: Aprenda conceitos fundamentais de Inteligência Artificial
- **Verificação de Respostas**: Sistema automático para verificar acertos
- **Design Responsivo**: Funciona perfeitamente em dispositivos móveis e desktop
- **Interface Moderna**: Design atraente com gradientes e animações suaves

## 🎮 Como Usar

1. Abra o arquivo `index.html` no seu navegador
2. Leia cada frase com atenção
3. Arraste as palavras disponíveis para os espaços em branco (___________)
4. Clique em "Verificar Respostas" para verificar seus acertos
5. Use "Recomeçar" para resetar o jogo
